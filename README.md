# foodbank-ux-mockup-project
A pro bono consulting project delivering a mobile app mockup for an Argentinian food bank, designed entirely through user stories and UX best practices.


This repository showcases a **pro bono consulting project** delivered for a food bank in Argentina in 2017. 
The goal was to design a modern, intuitive mobile experience that helps the organization better connect with donors, and families in need, and most importantly to improve the quantity and quality of food donations.

The project was created **end-to-end using Product Owner and UX methodologies**, with the full flow built explicitly *from user stories*. Duration of the project was 1 month.


## Project Goals

- Understand the needs of donors, beneficiaries, and food bank coordinators  
- Translate pain points into clear **user stories**  
- Create a **mobile app mockup** reflecting real-world workflows  
- Produce a structured, scalable solution the nonprofit can adopt later
- Find real sponsors to produce the actual the mobile app


## Deliverables

- **User Story Set** – covering donors, beneficiaries, and food bank staff  
- **User Journey Mapping**  
- **Mobile App Mockup** – all core screens  
- **Feature Concepts & Navigation Structure**  
- **Process Documentation** (see Word document in the repo)


## Approach

The design was developed using:

- **User stories** as the foundation for each feature  
- UX **mockups**  
- Product-focused thinking (value, feasibility, impact)
